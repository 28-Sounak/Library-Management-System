# Library Management System

A Java-based desktop application that simplifies library operations by providing an organized way to manage books, members, and issue/return transactions. This project demonstrates object-oriented programming concepts while offering a practical solution for basic library management.

---

## Features

- Book management
  - Add new books
  - Update book information
  - Delete books
  - View the complete book catalog

- Member management
  - Register new members
  - Update member details
  - Remove members
  - View member records

- Book circulation
  - Issue books
  - Return books
  - Track issued books
  - Maintain transaction records

- Search and filtering
  - Search books by title
  - Search by author
  - Search by category
  - Check book availability

- User-friendly interface
  - Simple desktop GUI
  - Easy navigation
  - Organized data presentation

---

## Technologies Used

- Java

## Getting Started

### Prerequisites

- Java JDK 8 or later
- IntelliJ IDEA, Eclipse, NetBeans, or any Java IDE

### Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/Library-Management-System.git
```

2. Open the project in your preferred IDE.

3. Build and run the application.
